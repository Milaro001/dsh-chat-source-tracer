# 验证说明

验证环境：DSH `0.2.1-rc.2`。记录日期：2026-10-20。

## 已发布版本

`v0.1.0-beta.1` 的验证范围：

- 27 项代码测试通过，覆盖历史用户、AI 和工具消息检索，单条长消息中后部匹配，消息身份与引用核对，模型 JSON 异常、有界重试、取消和超时。
- 深浅主题各 19 项浏览器检查通过，使用实际客户端代码、虚构会话和模拟 DSH 服务。
- DSH 实机验证了标签拖动排序、当前页面保持、重开后顺序保留、恢复默认及原有摘录定位。
- `.tgz` 在干净目录通过安装检查，Host 导入与 5 条路由注册成功。GitHub Actions 已完成依赖安装、语法检查、测试和打包试算。

## 压力测试与边界

检索层的合成压力测试覆盖 10 万条消息、约 5,209 万字符。该结果衡量文本检索能力，不能据此推定 DSH 页面、持久化日志和真实模型已通过相同规模的端到端验收。

仍需持续验证：

- 真实模型的归因准确率、长对话漏检率及语义改写的召回情况。
- DSH 原生历史加载、页面定位与极长会话的内存上限。
- 其他 DSH 版本、操作系统和更换版本后的档案迁移。

## 复现检查

```sh
npm ci --ignore-scripts
npm run check
npm test
node scripts/benchmark.mjs 100000
npm run preview
npm pack --dry-run --ignore-scripts
```

浏览器预览采用虚构会话和模拟服务，不调用真实模型。公开预览图也使用虚构内容。公开测试记录与分发文件不包含个人会话原文、密钥或私人截图。
