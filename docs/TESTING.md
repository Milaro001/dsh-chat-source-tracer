# 验证说明

验证环境：DSH `0.2.1-rc.2`。记录日期：2026-10-20。

## V0.3

版本：`0.3.0`，tag：`v0.3.0`。验证结果：

- 63 项代码测试通过，包含原文追问、草稿与附件保留、取消与迟到结果处理、回收站 50 条 / 30 天边界、排序、恢复及持久化失败重试。
- 深浅主题各 56 项界面检查通过，使用虚构会话和模拟服务。覆盖长选文与记录折叠、日期与全文按钮同排、主标签固定、横向工具、主会话档案切换、圆形加载指示和可关闭的分析动效。
- 原文操作条仅保留「追问 / 返回」。追问会聚焦原生草稿输入框，附上原文并保留现有草稿与附件；不会自动发送或发起分析。
- `.tgz` 通过干净目录安装检查，Host 导入与 8 条路由注册成功。分发文件与源码版本一致，并提供下载校验值。
- 真实 DSH 的视图切换与草稿 API 已核对；新增交互主要通过模拟服务验证。真实模型及不同 DSH 版本的端到端验收仍需补充。

## V0.2

版本：`0.2.0`，tag：`v0.2.0`。验证结果：

- `.tgz` 通过干净目录安装检查，Host 导入与 8 条路由注册成功；安装包包含跨会话模块、客户端和更新日志。
- 56 项代码测试通过，覆盖小窗搜索、分页与取消、跨会话候选检索、模型片段预算、来源重新核对、删除恢复和存储失败保护，以及日期显示、草稿插入和版本检查。
- 深浅主题各 44 项界面检查通过，覆盖搜索与输入法组合、迟到结果丢弃、标签排序、回收站恢复、跨会话跳转、长引文展开、返回位置与选区恢复，以及原文引用插入。
- DSH 实机已验证历史 AI 消息搜索与可见区域定位、跨会话候选检索、标签排序、回收站入口和短日期显示。
- 草稿插入、附件保留与关系模型的输出校验主要使用虚构会话及模拟服务验证。草稿插入接口已与 DSH 输入服务核对，真实草稿与真实模型的端到端验收仍需补充。

## V0.1 测试版

`v0.1.0-beta.1` 的验证范围：

- 27 项代码测试通过，覆盖历史用户、AI 和工具消息检索，单条长消息中后部匹配，消息身份与引用核对，模型 JSON 异常、有界重试、取消和超时。
- 深浅主题各 19 项浏览器检查通过，使用实际客户端代码、虚构会话和模拟 DSH 服务。
- DSH 实机验证了标签拖动排序、当前页面保持、重开后顺序保留、恢复默认及原有摘录定位。
- `.tgz` 在干净目录通过安装检查，Host 导入与 5 条路由注册成功。GitHub Actions 已完成依赖安装、语法检查、测试和打包试算。

## 压力测试与边界

检索层的合成压力测试覆盖 10 万条消息、约 5,209 万字符。该结果衡量文本检索能力，不能据此推定 DSH 页面、持久化日志和真实模型已通过相同规模的端到端验收。

仍需持续验证：

- 真实模型的归因准确率、长对话漏检率及语义改写的召回情况。
- DSH 原生历史加载、页面定位与极长会话的内存上限。
- 其他 DSH 版本、操作系统和更换版本后的档案迁移。

## 复现检查

```sh
npm ci --ignore-scripts
npm run check
npm test
node scripts/benchmark.mjs 100000
npm run preview
npm pack --dry-run --ignore-scripts
```

浏览器预览采用虚构会话和模拟服务，不调用真实模型。公开预览图也使用虚构内容。公开测试记录与分发文件不包含个人会话原文、密钥或私人截图。
