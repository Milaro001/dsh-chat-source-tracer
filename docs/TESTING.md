# V0.1 测试版验证范围

版本：`0.1.0-beta.1`。验证日期：2026-10-20。

## 已完成

- `npm run check`：Host、客户端、检索模块的 JavaScript 语法检查。
- `npm test`：27 项测试，覆盖较早用户/AI/工具消息检索、单条长消息中后部、消息身份与引用核对、排除当前/未来消息、模型 JSON 错误及有界重试、取消与超时等。
- 浏览器夹具：深色与浅色主题各 19 项检查；使用真实 `client.js`、虚构会话和模拟 DSH 服务。
- DSH 0.2.1-rc.2 实机：标签用鼠标拖动排序、保持当前页面、重开后保留顺序、恢复默认；保留已有摘录定位路径。
- 检索层合成压力测试：10 万条消息、约 5,209 万字符。它衡量检索层处理合成文本的能力，不代表 DSH 页面、持久化日志读取或真实模型已完成同规模端到端验收。
- 发布包采用明确文件清单，包含 `dsh.bundle`、patch、Host、客户端、检索模块、图标、语言文件和说明；原始个人会话及本地验证备份不随包上传。

## 仍需持续验证

- 真实模型在不同会话内容上的归因准确率和长会话漏检率。
- DSH 原生日志、历史加载与界面在极长会话上的端到端行为和内存上限。
- DSH 0.2.1-rc.2 以外版本及其他系统的兼容性。
- 更换版本或清理应用数据后的本地档案迁移；当前建议先导出备份。

没有公开真实个人聊天、模型密钥或原生应用的私人截图。`docs/preview.jpg` 使用虚构内容。

## 本地复现

```sh
npm ci --ignore-scripts
npm run check
npm test
node scripts/benchmark.mjs 100000
npm run preview
npm pack --dry-run --ignore-scripts
```

浏览器预览仅供本机使用，采用虚构会话和模拟服务，不会发起真实模型分析。修改运行时代码后应重新验证相应路径。
