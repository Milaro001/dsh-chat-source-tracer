# 上下文溯源透镜

**dsh-provenance-lens · V0.1 测试版（0.1.0-beta.1）**

和 AI 聊得久了，很容易遇到这种情况：眼前这句话看起来有道理，但它是根据我之前说的哪句话得出来的？是前面查到的材料，还是 AI 自己作出的推测？想回头确认，又得在很长的对话里翻来翻去。

这个插件就是为这种时候准备的。在 DeepSeek Harness 中打开「溯源」，选中一段文字，就能查看它可能关联的历史消息和工具材料，点一下依据回到原文。觉得有用的内容可以顺手存成摘录，把结论和假设留下来，最后导出一份 Markdown 档案。

它适合边聊边做研究、整理方案、反复调整需求的场景：帮助你核对一句话的来路，也让长对话里值得保留的内容更容易找回来。

> 这是事后分析出的可能关联，不是模型真实的生成过程，也不能证明模型当时确实采用了某条来源。V0.1 仍是测试版，真实超长会话和不同 DSH 版本的兼容性还需要继续验证。

## 它能帮你做什么

**选中一句话，看看它的依据。** 不用先整理整段会话。在同一条消息里选中要核对的词句或段落，插件会扫描此前的用户消息、AI 回答和工具材料，挑出相关片段交给归因模型分析，区分有原文支持的内容与推论。一次最多选择 6,000 字。

**点依据，回到那条原话。** 引用会核对消息编号和文本；较早的消息还没显示时，会尝试让 DSH 加载相应历史，再定位到目标消息内部。既能找你说过的话，也能找 AI 先前的结论和工具返回的材料。找不到时会明确提示。

**把有用的内容留下来。** 摘录保留选中的原句，之后可以再跳回原处；结论和假设有各自的页面，方便回头看哪些已经决定、哪些还需要验证。觉得依据关联得不对，可以点「不准」反馈并重新分析。档案支持 Markdown 和 JSON 导出，便于备份和继续整理。

**需要时，再补一轮网页检索。** 配置了可用的 DSH web provider 后，可以从面板补充查找网页材料。补查结果会与会话里的既有依据区分展示，避免把后来找到的东西当成原回答当时就有的证据。

## 长对话怎么处理

它会读取当前会话的完整逻辑日志，在选中内容之前的消息中分片检索，而不是只看最近几轮。单条很长的回答，中间和尾部也会参与检索。扫描时分批让出执行时间，并支持取消，尽量减少长任务卡住界面的情况。

交给归因模型的是筛选后的候选片段，当前候选文本预算约为 42,000 字符。面板显示的「扫描消息数」和「交给模型的片段数」因此不同。词汇检索可能漏掉完全改写、没有共享词的关联；「未找到依据」不等于整个对话绝对没有依据。读取能力也受 DSH 和本机内存限制。

目前检索层的合成压力测试覆盖了 10 万条消息、约 5,209 万字符；这不等于已在真实 DSH 页面中验收同等规模的对话。具体范围见 [验证说明](docs/TESTING.md)。

## 用起来是什么感觉

输入框旁的「溯源」按钮是开关，也支持 `⌘⌥T` / `Ctrl+Alt+T`。开关时蓝色光段沿边缘绕行一周；开启后保留较柔和的蓝色边框，聊天背景底部有渐变和缓慢波浪，作为进入溯源状态的提示。背景效果放在文字、消息和输入框下面，不拦截点击。

右侧小窗支持六种主题、字号和尺寸调整，关闭与收起带淡出动效，列表到底时有轻微回弹。鼠标经过可点击的操作和引用时，文字与边框会亮一点；「不准」带淡红色边框，方便辨认。系统开启「减少动态效果」时，相应动画会停用。

「溯源、结论、假设、摘录」四个标签可以自己排序：按住标签或左侧小点，拖到想放的位置再松手。排序不会切换当前页面，下次打开也会记住。键盘选中标签后，按 Option/Alt + 左右方向键也能移动；设置中的「标签顺序 → 恢复默认」可以重置。

## 安装与开始使用

这是 **DeepSeek Harness 插件**。本版实机验证环境为 **DSH 0.2.1-rc.2**，其他版本尚未逐一验收。需要先在 DSH 配好可用的模型提供方，归因分析才可运行。

推荐到 [V0.1 测试版 Release](https://github.com/Milaro001/dsh-provenance-lens/releases/tag/v0.1.0-beta.1) 下载 `.tgz` 安装包。终端使用 DSH 的插件安装命令：

```sh
dsh plugin add https://github.com/Milaro001/dsh-provenance-lens/releases/download/v0.1.0-beta.1/dsh-provenance-lens-0.1.0-beta.1.tgz
```

也可以用仓库地址作为安装来源：

```sh
dsh plugin add https://github.com/Milaro001/dsh-provenance-lens
```

若桌面版没有把 `dsh` 命令加入 PATH，请在 DSH 插件管理界面的安装入口使用相同来源。更新后重载插件，确认「溯源」入口出现。如果安装过其他来源的开发版本，请只保留一个版本启用，以免重复显示入口。

开始使用只需要几步：

1. 打开一段会话，点击输入框旁的「溯源」。
2. 在一条消息内选中想核对的文字，等待面板分析。
3. 查看引用的角色与原文，点击依据回到相应消息。
4. 要留下的内容点「存为笔记」，需要整理时查看结论、假设和摘录。
5. 从档案导出 Markdown 或 JSON，保留自己的备份。

Release 中的 ZIP 是源码交付包；`.tgz` 是插件安装包。版本号中的 `beta` 表示测试版。GitHub 发布与社区市场收录分别进行，当前不宣称已被市场收录。

## 数据会去哪里

分析按需读取当前会话，不自动分析其他会话。归因时，选中内容和检索到的历史片段会发送给 **DSH 当前配置的模型提供方**，可能产生模型费用。补充网页检索还会使用配置的 web provider。

摘录、档案和界面偏好保存在本机浏览器的 `localStorage`，目前不跨设备同步；清理应用数据或存储失败可能导致丢失，建议定期导出。提示词会遮盖部分常见密钥格式，但这不是完整的敏感信息识别器。
